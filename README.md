## <p align="center"> NerdFont Patcher Nix-Shell. </p>

#### Usage.

1. Clone repo.
2. Enter nix-shell.
```nix
nix develop
```

3. Make script executable.
```bash
chmod +x font-patcher.sh
```

4. Run script.
```bash
./font-patcher.sh ./<NAME_OF_FONT_FOLDER> ./<NAME_THE_FOLDER_TO_OUTPUT_PATCHED_FONTS>
```

5. Exit nix-shell when done.
```nix
exit
```
